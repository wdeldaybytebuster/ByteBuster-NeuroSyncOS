# Code of Conduct

## Our pledge

We want NeuroSync Sovereign OS to be a welcoming project for anyone testing it,
filing issues, or contributing code — regardless of experience level,
background, or how they found the project.

## Expected behavior

- Be respectful and constructive in issues, pull requests, and discussions.
- Focus feedback on the code and the problem, not the person.
- Accept that this is an Alpha-stage, largely solo-maintained project — response
  times and scope decisions may be slower or narrower than a larger project's.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language or jokes.
- Publishing others' private information (including API keys, credentials, or
  other secrets accidentally shared in an issue) without consent.
- Sustained disruption of issues, pull requests, or other project spaces.

## Scope

This Code of Conduct applies within all project spaces (issues, pull requests,
discussions) and when representing the project in public spaces.

## Enforcement

Instances of unacceptable behavior may be reported by opening a
[private security advisory](https://github.com/wdeldaybytebuster/ByteBuster-NeuroSyncOS/security/advisories/new)
or contacting the maintainer directly via their GitHub profile. Reports will be
reviewed and addressed as promptly as possible; the maintainer may remove,
edit, or reject comments, commits, issues, and other contributions that don't
align with this Code of Conduct.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
