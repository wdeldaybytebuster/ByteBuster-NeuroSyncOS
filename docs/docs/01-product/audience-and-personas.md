# Audience and Personas

## Target Audience

The primary target audience for NeuroSync Sovereign OS consists of **Beginner Hobbyists and Freelancers** who require absolute privacy and data sovereignty for their projects. They want to execute automated AI workflows locally on their own consumer hardware (including legacy laptops) without incurring cloud infrastructure costs or paid LLM API key subscriptions.

## Personas

### Persona 1: Alex, Freelance Content Creator
- **Role:** Independent writer, researcher, and marketer.
- **Need:** High-privacy automation for writing copy and researching clients.
- **Pain:** High monthly cloud subscription costs and fear of client data leaking into public LLM training sets.
- **Goal:** Run local, secure AI agents to draft and index client articles entirely offline.

### Persona 2: Sam, Hobbyist Developer
- **Role:** Junior programmer building self-hosted projects.
- **Need:** Simple, lightweight local tools to orchestrate multi-agent runs.
- **Pain:** Complex setup of Docker, Kubernetes, or DuckDB engines that crash on a 6-year-old laptop.
- **Goal:** Run simple, local-first DAGs using a zero-configuration SQLite stack.
