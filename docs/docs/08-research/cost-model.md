# Cost Model

## Hardware Economics & Token Burn

The core vision is local-first, meaning the baseline operating cost is **0.00 USD/day** for offline mock/free-tier routing [1].
- **Paid Upgrades:** If user unlocks paid models (e.g. OpenRouter), token ledger monitors usage.
- **Budget Caps:** System caps daily spend based on `config.toml` options (default: $2.00/day limit).
