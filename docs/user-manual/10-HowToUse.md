# 9. How to Use This App Every Day

This last section is not another dashboard. It is a simple guide for using the app day to day.

## Start with the whole picture

When you open the app, do not try to learn every screen at once. Start with:

1. System View, to see how things are doing.
2. Project Planner, if you have something to ask the app to do.
3. Approvals and Tools, if a plan needs your permission.
4. Task Runner, if you want to see what is running.

That order is not a rule. It is just a simple way to begin.

## Learn one screen at a time

Each screen has its own job. If you try to understand them all at once, the app can feel crowded. It is easier to learn one screen, use it, then move to the next.

A good way to learn a screen is to ask three questions:

- What is this screen for?
- What can I see on it?
- What can I change on it?

If you can answer those three questions, you usually know enough to use the screen.

## Remember the basic flow

A normal workflow often looks like this:

1. You describe what you want.
2. The app turns that into a plan.
3. You approve the plan.
4. The app runs it.
5. The app stores the results and keeps useful memories.
6. You can check the results later.

If you remember that flow, the screens make more sense because each one fits into a step.

## Read before you approve

The app can suggest, draft, and prepare, but some actions still need a person. If you are unsure, slow down. A few extra seconds here can save a lot of fixing later.

Approval is a choice. It is not a formality. If something looks risky or unclear, it is okay to reject it and look again.

## Keep an eye on storage and memory

Storage and Memory are easy to ignore, but they matter. If the app seems to forget things, those are good places to check. If you are about to make a big change, back up first.

A backup is a safety net. Treat it like one.

## Treat the watcher as a helper

Background Watcher is there to notice things. It is useful, but it is not the whole story. Use it as an early hint, not as the final answer.

## Know where responsibility lives

A helpful map is this:

- System View is for the big picture and basic settings.
- Project Planner is for describing what you want.
- Approvals and Tools is for permission and control.
- AI Model Settings is for choosing where requests go.
- Task Runner is for running and watching work.
- Storage and Backups is for keeping records safe.
- Memory is for remembering useful things.
- Background Watcher is for noticing and suggesting.

If something goes wrong, that map can help you figure out where to look first.

## When in doubt

If you are not sure what is happening, try these in order:

- reread the plan,
- check the status of a run,
- look for an alert or approval item,
- check storage or memory if something seems forgotten,
- ask whether the problem is the request, the model, the connection, the schedule, or the run itself.

That simple checklist solves a lot of confusion.

## A final reminder

This app is built around human control. Many things can be prepared automatically, but important actions are meant to be checked by a person.

If something looks unsure, slow down and read it again. That is the safest and easiest habit to build.
