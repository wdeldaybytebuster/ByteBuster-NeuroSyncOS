# NeuroSync Sovereign OS — User Manual

## 3. ScopeLogic — the planning and instruction screen

ScopeLogic is where you tell the app what you want and ask it to turn that idea into a plan.

A simple way to think about it is this: ScopeLogic is the “what should we do?” part of the app.

### What it does

ScopeLogic helps you:

- Write a request
- Turn that request into a set of steps
- Review the steps before anything runs
- Start a workflow when you are ready

It is not the same as just pressing “go.” ScopeLogic is more like drafting a recipe before cooking.

### Main parts of ScopeLogic

- **The chat or request area**
  This is where you type what you want done. Try to be clear. The more specific you are, the better the plan can be.

- **The plan or proposal**
  After you ask, the app may build a list of steps. Each step usually has a job to do. You can read the steps before you approve them.

- **Reset tools**
  Sometimes you want to start over. ScopeLogic usually gives you a way to clear the current session and begin again.

### How a normal flow looks

1. You type a request.
2. The app turns it into steps.
3. You review the steps.
4. If the steps look good, the plan can move to approval in PortGrid.
5. If not, you can change the request or reject the plan.

That means ScopeLogic and PortGrid often work together. ScopeLogic makes the plan. PortGrid helps you decide whether to allow it.

### Tips for better requests

- Tell the app what result you want.
- Say whether you want something fast, careful, cheap, or detailed.
- If your request is big, break it into smaller pieces.
- If the first plan looks wrong, that is normal. You can try again.

### What ScopeLogic is not

ScopeLogic does not run the final job by itself. It helps build and refine the idea. The actual running and scheduling usually belong to other parts of the app.

### When to use ScopeLogic

Use ScopeLogic at the start of a task, when you have an idea and want the app to shape it into steps. Also use it when a plan needs editing before it goes any further.
