# NeuroSync Sovereign OS — User Manual

## 9. Everyday use: a few good habits

This last part is not a separate screen. It is a short guide for using the app day to day.

### Start simple

When you open NeuroSync, do not try to learn every screen at once. Start with:

1. **System View** to see how things are doing
2. **ScopeLogic** if you have something to ask the app to do
3. **PortGrid** if a plan needs your approval
4. **CoreExec** if you want to see what is running

### Read before you approve

The app can suggest, draft, and prepare, but some actions still need a person. If you are unsure, slow down. A few extra seconds here can save a lot of fixing later.

### Keep an eye on memory and storage

Cerebro and BaseVault are easy to ignore, but they matter. If the app seems to forget things, those are good places to check. If you are about to make a big change, back up first.

### Treat the watcher as a helper

ScoutDaemon is there to notice things. It is useful, but it is not the whole story. Use it as an early hint, not as the final answer.

### Know where responsibility lives

- ScopeLogic helps shape the plan.
- PortGrid helps you decide whether to allow it.
- RouteSwitch helps choose where requests go.
- CoreExec runs the approved work.
- BaseVault keeps the records.
- Cerebro helps the app remember.
- ScoutDaemon keeps watch.

If something goes wrong, that map can help you figure out where to look first.

### When in doubt

- Reread the plan.
- Check the status of a run.
- Look for a backup or memory refresh.
- Ask whether the problem is the request, the model, the connection, the schedule, or the storage.

## That’s the whole manual

NeuroSync Sovereign OS is built from a few simple ideas:

- See what is happening
- Shape what should happen
- Approve what is worth doing
- Run the work safely
- Keep records and memory
- Watch in the background

If you keep those ideas in mind, the screens will make more sense.
