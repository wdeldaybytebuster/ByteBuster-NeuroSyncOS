## How this manual is written

Each dashboard section usually has the same four parts:

- what the screen is,
- what you can see on it,
- what you can do on it,
- how to use it in real life.

That means each section is meant to be practical. It is not just a list of buttons. It is a short guide for using that screen.

## What the manual covers

The manual covers the main dashboards and set-up views that a user is likely to touch, plus the most important options on each screen. It also includes a glossary for words that show up in more than one place.

## A quick note

Some screens have extra details, developer-mode details, or advanced settings that are not fully expanded here. If you want a section blown up into a more detailed step-by-step walkthrough, that can be added.
