# NeuroSync Sovereign OS — User Manual

**Audience:** New and casual users.  
**Reading level:** Plain, simple English (about 6th grade).  
**What this manual covers:** The main screens in the app, what each one does, and the most important choices on each screen.

---

## How to use this manual

NeuroSync Sovereign OS is a local computer program that helps you run little jobs, talk to AI models, keep memories, and watch what the system is doing — all on your own machine.

When you open the app, you will usually see a sidebar with a list of "modules" (big feature areas). Each module is its own screen. You can click any module name to jump to it.

If a button, slider, or menu is not on your screen yet, that usually means it only shows up after your computer has been set up enough, or after a certain feature is turned on. This manual tries to explain what things mean, not just where to click.

---

## Common ideas you will see everywhere

- **Dashboard:** The main page for a module. It shows the most important things at a glance.
- **Set-up:** A page with settings and choices for that module.
- **Dark mode and Light mode:** The app can be dark or bright. You can change it.
- **Simple mode and Developer mode:** Simple mode shows friendly words. Developer mode shows more technical words and details. You can switch this in the top bar.
- **Projects:** The app can focus on one workspace at a time. Some screens change depending on which project you picked.

## 1. System View — the main overview screen

This is the app’s front page. It is named **System View**, but the app sometimes also calls it the **System Dashboard** or **At a Glance** screen.

### What it does

System View gives you a quick picture of the whole app. It helps you answer questions like:

- Is the system busy right now?
- How many workers are running?
- How much has the AI been used today?
- Is the memory part working normally?

It also has a setup page where you can change a few basic preferences for the whole app.

### Main parts of the dashboard

- **System KPIs (key numbers)**
  This section shows big numbers such as:
  - How many workers the app sees
  - How busy it is
  - How many tokens were used in the last day
  - How much the last day’s usage cost
  - How many memory vectors are stored

  Think of this like a car dashboard. It does not control the car. It just tells you what is happening.

- **Needs Your Attention**
  This part shows things that may need your help. If nothing is wrong, it usually says everything is clear.

- **AI Memory Health**
  This shows the status of the memory system (Cerebro). It can tell you things like how many pieces of memory it has and whether it was updated recently. There is also a button to refresh memory scores.

- **Scheduled Workflows**
  This shows jobs that are set to run later on a schedule. If nothing is scheduled, it will say so.

### Set-up part of System View

On the Set-up tab, you can change a few global choices:

- **Refresh rate**
  This controls how often some parts of the app ask the server for new information. Faster means more up to date. Slower can be easier on the computer.

- **Max concurrent tasks**
  This is the largest number of tasks that can run at the same time. If you set it too high, the system may get crowded. If you set it too low, work may take longer.

- **Claim batch size**
  This controls how many tasks can be claimed together in one batch.

- **Log level**
  This chooses how much detail the app writes into its activity log.
  - More detail can help with fixing problems.
  - Less detail is quieter and simpler.

- **Theme**
  You can choose:
  - Dark
  - Light
  - System (follows your computer’s setting)

- **Show Helpful Tips**
  When this is on, the app may show short explanations next to tricky words or features.

- **Reduced motion**
  If you turn this on, the app will try to use fewer animations.

### When to use System View

Use this screen when you first open the app, or when you want a quick health check. It is also a good place to change basic settings that affect the whole app.
