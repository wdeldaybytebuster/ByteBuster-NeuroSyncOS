# NeuroSync Sovereign OS — User Manual

## 7. Cerebro — the memory screen

Cerebro is the part of the app that tries to remember useful things over time. It is not just a list of old messages. It is the system’s memory layer.

A simple way to think about it is this: Cerebro is the notebook and the filing system for what the app should keep in mind.

### What it does

Cerebro helps the app:

- Store information it may need later
- Keep track of memories, notes, or saved facts
- Refresh and organize that memory when needed
- Show you whether the memory system is healthy

Different parts of the app may ask Cerebro for information. That makes memory one of the things that helps the system feel more continuous instead of starting fresh every time.

### Main parts of Cerebro

- **Memory health**
  This shows whether the memory system is doing okay. It may tell you things like:
  - How many items it has stored
  - Whether it is active or idle
  - When it was last updated

- **Stored vectors**
  You may see this word in Cerebro. A vector is a way the app can store information so it can search and compare it later. You do not need to know every technical detail to use the screen, but it helps to know that “more vectors” usually means more stored memory pieces.

- **Refresh tools**
  Cerebro may let you update memory scores or consolidate memory. That means it can tidy, re-check, or refresh stored information so the app sees a cleaner picture.

### How it fits with the rest of the app

Cerebro often works behind the scenes. You may not open it every day. But other screens may rely on it:

- A plan may use memory to remember earlier context.
- A run may depend on stored facts.
- The system may check memory to decide what it already knows.

That means Cerebro is less about control and more about continuity. It helps the app remember what matters.

### A simple way to read memory status

- If memory looks full but not healthy, the app may need a refresh.
- If memory is quiet, that may be normal when nothing new has happened.
- If memory seems missing or stale, it may mean the system has not updated recently.

Memory status is a signal, not a judgment. It tells you what the system sees right now.

### Good habits here

- Use the refresh or consolidation tools when memory feels messy or out of date.
- Do not assume memory is perfect. It is a helper, not a guarantee.
- If something should be remembered, make sure it is stored in a place the app can keep.
- If memory seems wrong, check whether the information was saved correctly in the first place.

### When to use Cerebro

Use Cerebro when you want to:

- Look at memory health
- Refresh stored memory
- Understand why the app seems to remember some things and not others
- Check whether the memory system is active
