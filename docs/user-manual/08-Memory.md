# 8. Memory

## What this screen is

Memory is the part of the app that tries to remember useful things over time. It is not just a list of old messages. It is the system’s memory layer.

In technical terms, this screen is also called Cerebro. From the user’s point of view, it is the notebook and filing system for what the app should keep in mind.

This screen is useful when you want to:

- look at memory health,
- see how much the app has stored,
- refresh or tidy stored memory,
- understand why the app remembers some things and not others.

## What you can see on it

### Dashboard page

The dashboard page focuses on the state of memory.

You may see:

- memory health,
- how many items are stored,
- whether memory is active or idle,
- when memory was last updated,
- a way to refresh memory scores or consolidate memory.

#### Memory health

This shows whether the memory system is doing okay. It may tell you things like:

- how many items it has stored,
- whether it is active,
- when it was last updated.

Memory status is a signal, not a judgment. It tells you what the system sees right now.

#### Stored memory

You may see references to stored memory items or vectors. A vector is a way the app can store information so it can search and compare it later.

You do not need to know every technical detail to use the screen. It is enough to know that more stored memory usually means more pieces the app can look through later.

#### Refresh tools

Memory may let you update memory scores or consolidate memory. That means it can tidy, re-check, or refresh stored information so the app sees a cleaner picture.

This is useful when memory feels messy, out of date, or incomplete.

### Set-up page

The Set-up page for this screen is about how memory behaves and how it is maintained.

You may see settings that affect:

- how memory is refreshed,
- how memory is organized,
- how the app uses stored information.

The exact controls depend on the screen, but the general idea is the same: you are shaping how the app remembers and maintains what it remembers.

## What you can do on it

On Memory, you can:

- check memory health,
- see how much is stored,
- refresh memory,
- consolidate memory,
- read when memory was last updated,
- adjust memory settings if the screen provides them.

## How it works

Memory works by storing information the app may need later.

Other parts of the app may ask Memory for information. That makes memory one of the things that helps the system feel more continuous instead of starting fresh every time.

A simple way to think about it is this: Memory is not the place where work happens. It is the place where useful context is kept so the system can remember it later.

Memory status can change for different reasons. If nothing new has happened, memory may be quiet. If the system has not updated recently, memory may seem stale. If memory is full but not healthy, it may need a refresh.

## How to use it in real life

Use Memory when:

- you want to know whether the app is remembering things,
- you want to refresh stored memory,
- you want to understand why the app seems to remember some things and not others,
- you want to check whether memory is active.

A good habit is to refresh or consolidate memory when it feels out of date. Another good habit is to remember that memory is a helper, not a guarantee.

If something should be remembered, make sure it is stored in a place the app can keep. If memory seems wrong, check whether the information was saved correctly in the first place.

## Small tips

- Do not assume memory is perfect.
- If memory seems stale, a refresh may help.
- If the app forgets something, check whether it was stored correctly.
- Use memory as a continuity tool, not as a substitute for checking the actual work.
- If memory status looks unusual, treat it as a clue and look closer.
